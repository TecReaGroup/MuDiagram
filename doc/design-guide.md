# 界面设计规范（与品牌无关）

本文总结一套**可移植的界面设计逻辑**：分层方式、布局、组件、交互状态、动效、加载与空状态。
文中不出现任何具体色值、字号、尺寸、品牌元素，也不绑定某个框架或组件库。换到其他设计系统时，只需把文中的**角色名**映射到对应系统的 Token / 组件即可（映射示例见文末附录）。

---

## 0. 设计逻辑总览

整套规范围绕五条判断展开，后面所有规则都是它们的推论：

1. **内容优先。** 界面是承载内容的容器，应保持中性、安静；屏幕上最醒目的永远是用户的内容（文档、图表、图片），而不是控件。
2. **颜色只表达含义。** 强调色只表达"当前焦点 / 核心功能"，状态色只表达"成功 / 危险"等状态。不为装饰而上色。
3. **层级靠表面和阴影，不靠颜色。** 用少量表面层级与阴影档位区分"底 / 内容 / 浮层"，让换肤时结构不变。
4. **决策集中，调用处只组合。** 视觉决策只在 Token 和组件内部做一次；使用组件的地方只决定"放在哪里"，不决定"长什么样"。
5. **安静直到需要。** 次要操作在悬停 / 聚焦时才出现，危险色只在即将执行危险操作时出现，动效只在状态变化时出现。

## 1. 设计系统分层

设计系统按"抽象程度"分为五层，上层只能依赖下层：

| 层 | 内容 | 职责 | 禁止 |
| --- | --- | --- | --- |
| ① Token | 颜色角色、表面、阴影档、圆角档、字号档、时长档、缓动、动画 | 定义"有哪些可选值" | 出现在业务代码中的裸值 |
| ② 样式原语 | 按尺寸档 × 色调组合好的控件样式、焦点样式、表面外壳、文字层级 | 定义"值如何组合" | 被调用方覆盖尺寸 / 圆角 / 颜色 |
| ③ 通用组件 | 弹窗、下拉、开关、内联编辑、确认删除、浮层关闭逻辑 | 封装"行为 + 无障碍" | 依赖任何业务功能 |
| ④ 业务组件 | 某个功能内部的卡片、面板、列表行 | 组合下层，表达业务 | 被其他功能直接复制样式 |
| ⑤ 页面 | 外壳与区域布局 | 决定"东西放在哪里" | 定义可复用的视觉样式 |

### 1.1 核心规则

- **只引用语义角色**（如"主文字""次要文字""表面""分隔线"），不引用色板值。新需求先判断能否用已有角色表达，不能才新增角色。
- **变化通过"档位"实现，不通过"覆盖"实现。** 需要更小的按钮，就新增一个尺寸档；而不是在使用处追加一个冲突的尺寸类。覆盖在原子化 CSS 中优先级不可控，会静默失效。
- **使用处只允许追加布局信息**：定位、外边距、宽度、显隐、响应式显隐。
- **状态由语义属性驱动，而非样式参数。** 选中、展开、按下、勾选分别由 `aria-current` / `aria-expanded` / `aria-pressed` / `aria-checked` 驱动样式。组件不接收 `isActive`、`selected` 这类只为换样式的布尔参数——这样无障碍语义和视觉永远一致。
- **抽取时机**：同一模式出现第 2–3 次才提取为通用组件；只用一次的留在业务内，避免过早抽象。

### 1.2 Token 应覆盖的角色清单

迁移到新设计系统时，确保以下角色都有对应值：

| 类别 | 角色 |
| --- | --- |
| 表面 | 页面底、内容表面、凹陷表面、悬停底 |
| 线条 | 默认分隔线、强调分隔线（悬停 / 选中） |
| 文字 | 主文字、次要文字、弱提示文字 |
| 强调 | 强调色、强调柔和底、强调底上的文字 |
| 状态 | 成功 / 成功柔和底、危险 / 危险柔和底 |
| 阴影 | 静止、悬浮（卡片悬停）、浮层 |
| 圆角 | 小控件、控件、卡片、弹窗（逐级增大） |
| 字号 | 辅助、元信息、控件、正文、标题若干档 |
| 动效 | 短 / 中 / 长三档时长，一条主缓动曲线 |

规律：**柔和底用作背景，同组深色用作其上的文字与图标**，保证任意主题下对比关系不变。

## 2. 布局规范

### 2.1 外壳（Shell）

一个应用只保留少数几种外壳，新页面必须归入其中之一，不为单页发明新骨架。常见两种：

**浏览型外壳**——列表、管理、设置类页面：

```
┌────────┬───────────────────────────────────────┐
│ 侧栏    │ ┌─ 主内容表面 ───────────────────────┐ │
│ 标识    │ │ 顶栏：[左] [   搜索（居中）  ] [右] │ │
│ 导航    │ │                                   │ │
│ 分组    │ │   限宽居中的内容容器               │ │
│ …       │ │   页标题 → 工具条 → 内容           │ │
│ 主操作  │ │                                   │ │
└────────┴─┴───────────────────────────────────┴─┘
```

- 侧栏固定宽度、吸顶、占满视口高度；主操作贴底。
- 主内容是浮在页面底上的一张表面；窄屏退化为全幅、无边框。
- 顶栏用"两侧等宽弹性列 + 中间内容列"的三列结构，保证中间元素永远视觉居中，不受两侧按钮数量影响。

**工作型外壳**——编辑器、画布等全屏工作页面：

```
┌──────────────────────────────────────────────────┐
│ 顶栏：标识 · 面包屑 · 状态               [操作] │
├───────────────────────────────────┬──────────────┤
│ 主工作区（弹性填满）               │ 侧面板        │
│                                   │ （固定宽度）  │
└───────────────────────────────────┴──────────────┘
```

- 根容器占满视口且自身不滚动，滚动只发生在各面板内部。
- 工作区与侧面板是并列的独立表面，间隙统一。

### 2.2 内容区

- 固定阅读顺序：**页标题 → 可选说明 → 工具条（筛选 / 排序 / 视图切换）→ 内容 → 空状态**。
- 卡片集合用响应式网格，列数随宽度递增，间距固定；不用换行 flex 模拟网格。
- 间距只分两种关系：**组内**（紧）与**组间**（松）。同组元素用父级的统一间隔，不在子元素上各自写外边距。
- 间距、尺寸全部落在统一网格的倍数上。

### 2.3 响应式

移动优先；断点只用于**结构切换**，不用于微调数值。

| 宽度从宽到窄 | 结构变化 |
| --- | --- |
| 宽 → 中 | 并排的侧面板变为从边缘滑出的浮层抽屉 |
| 中 → 窄 | 侧栏隐藏，其主操作移入顶栏并变为图标按钮；主表面变为全幅 |
| 窄 → 最窄 | 次要文字隐藏只留图标；左右分栏改为上下堆叠 |

- 弹窗、浮层宽度一律写成"目标宽度与视口减边距取较小值"，任何宽度都不溢出。
- 页面设最小宽度下限；全局预留滚动条槽位，避免长短页面切换时内容左右跳动。

### 2.4 弹性布局铁律

- 含可截断文本的弹性子项必须允许收缩到 0 宽度，否则截断失效。
- 纵向弹性布局中的滚动区必须允许收缩到 0 高度，否则无法滚动。
- 图标、按钮、徽标等禁止被挤压。
- 用户输入的名称（标题、文件名、URL）单行截断；长正文允许在任意位置断行，防止撑破容器。
- 会变化的数字使用等宽数字，避免抖动。

## 3. 表面、层级与叠放

| 表面角色 | 含义 | 用途 |
| --- | --- | --- |
| 页面底 | 最底层 | 页面背景、大弹窗的侧栏背景 |
| 内容表面 | 承载内容 | 卡片、面板、弹窗、菜单 |
| 凹陷表面 | 嵌入 / 次级 | 分段控件底、气泡、选中项、骨架占位 |

| 阴影档 | 用途 |
| --- | --- |
| 静止 | 静止的卡片、按钮、面板 |
| 悬浮 | 卡片悬停、被选中的选项卡片 |
| 浮层 | 菜单、浮动面板、弹窗、窄屏抽屉 |

- 卡片 / 面板外壳是一个复用原语（表面 + 边框 + 静止阴影 + 圆角），不在各处手写组合。
- **圆角嵌套递减**：内层圆角比外层小一档；视觉上内外边缘保持同心。
- **叠放层固定为几层**（低 → 高）：页面内容 → 卡片内悬浮操作 → 下拉菜单 → 浮动面板 / 抽屉 → 模态弹窗。新浮层必须归入其一，不自造层级值。模态弹窗优先使用平台原生的顶层机制。

## 4. 交互状态

| 状态 | 规则 |
| --- | --- |
| 悬停 | 幽灵控件出现悬停底；文字从次要变为主文字；卡片轻微上浮 + 边框加强 + 阴影升一档 |
| 键盘焦点 | 统一焦点环，只在键盘聚焦时出现；输入框及其容器使用"强调色边框 + 柔光"的输入焦点样式 |
| 选中 | 导航：反色实底；分段控件：凸起为内容表面；菜单项：凹陷底 + 对勾；选项卡片：边框加强 + 阴影升档 + 对勾 |
| 展开 | 触发器保持按下外观，指示箭头旋转 |
| 禁用 | 降低不透明度并禁止指针事件；不额外换色 |
| 危险 | 静止时与普通控件一致，悬停才显示危险色；只有最终确认按钮使用危险实底 |
| 处理中 | 触发控件禁用并内嵌旋转指示；不使用全屏遮罩 |

原则：**选中不改变尺寸**（字重可变，但不能引起布局移动）；**所有状态在键盘和触屏下都可达**。

## 5. Widget 规范

### 5.1 按钮

文字按钮与纯图标按钮共享同一套**色调 × 尺寸**矩阵。

| 色调 | 场景 |
| --- | --- |
| 主要 | 区域内唯一的主操作 |
| 次要 | 并列的次要操作、取消 |
| 幽灵 | 工具栏、面板头、关闭、展开 |
| 强调 | 已激活的核心功能开关 |
| 安静危险 | 删除入口（悬停才变危险色） |
| 危险 | 确认弹窗里真正执行删除的按钮 |
| 反色 | 位于反色（选中）表面上的操作 |

| 尺寸档 | 场景 |
| --- | --- |
| 小 | 卡片内、列表行内 |
| 中（默认） | 工具栏、面板头 |
| 大 | 表单提交、导航项 |
| 特大 | 与输入框同高的操作、侧栏主操作 |

- 同一行控件取同一档；一个区域最多一个"主要"按钮。
- 按钮内图标尺寸由尺寸档决定。
- 纯图标按钮必须有无障碍名称，并提供悬停提示。

### 5.2 导航项

- 统一高度、左图标、文字、右侧可选计数；计数为 0 不显示。
- 选中态由路由或 `aria-current` 驱动，呈反色实底。
- 行内附加操作放在链接**旁边**的覆盖层中（交互元素不能嵌套），选中行内的操作使用反色色调。

### 5.3 卡片

- 结构：**预览区 → 标题 → 元信息行（图标 · 状态 · 时间）→ 悬停显示的操作**。
- 整卡可点击时，用标题链接的伪元素铺满卡片作为点击区；卡内其他按钮提升到其上层。
- 预览区使用与内容表面区分的浅底纹，让缩略图有"画布感"。

### 5.4 悬停显示操作（Hover Reveal）

- 列表行 / 卡片的次要操作默认隐藏，父级悬停或内部获得焦点时显示。
- **只在支持悬停的设备上隐藏**；触屏设备始终显示。
- 操作出现时，被其覆盖的尾部信息同步隐藏，不重叠。

### 5.5 菜单与浮层

- 浮层面板：内容表面 + 浮层阴影 + 小内边距；项之间留细缝，避免选中底与悬停底连成一片。
- 单选菜单项使用 `menuitemradio` + `aria-checked`，选中以凹陷底 + 对勾表示。
- 关闭逻辑统一封装：点击外部、按 Escape、焦点进入内嵌 iframe 时关闭。
- 浮层的变换原点与弹出方向一致（向下弹出则原点在上沿）。
- 触发器声明 `aria-haspopup` 与 `aria-expanded`。
- 嵌套在模态弹窗中的浮层优先消费 Escape，避免一次按键关闭两层。

### 5.6 下拉选择

- 不使用无法定制弹出层的原生选择框，使用自定义下拉。
- 触发器外观与输入框完全一致，展开期间保持焦点外观；选项以凹陷底 + 对勾表示选中。
- 选项过多时按可见条目数限高并滚动（见第 6 节）。

### 5.7 弹窗

- 基于平台原生模态机制；调用处只决定尺寸与内边距。
- 内容仅在打开时挂载，表单每次打开都从初始值开始。
- 必须关联标题，有说明时关联描述。
- 关闭途径：Escape、点击遮罩、右上角关闭按钮。
- **底部按钮**：取消在左，确认在右；第三个操作放中间。
- 大型弹窗（如设置）使用"左侧分区导航 + 右侧可滚动内容"，窄屏变为"顶部横向导航 + 下方内容"。

### 5.8 删除确认

- 不可撤销的删除必须经过确认弹窗：危险图标 + 标题 + 包含对象名的描述 + 取消 / 删除。
- 默认焦点在"取消"，防止回车误删。
- 可撤销的删除（移入回收站）不弹确认。

### 5.9 表单

- 字段结构：标签在上、控件在下；字段之间统一间距。
- 机器字符串（URL、ID、密钥）使用等宽字体。
- 设置类表单**失焦保存**，开关**切换即保存**，不按键即请求。
- 校验 / 测试结果以"图标 + 单行文字"紧跟触发按钮，过长截断并提供完整提示。

### 5.10 内联编辑

- 替换原行内容，保持原行高度与图标位置。
- 回车或失焦提交，Escape 取消；空值或未改动不提交。

### 5.11 开关与分段控件

- 开关用于即时生效的布尔设置：文字在左，开关贴右，`role="switch"`。
- 分段控件用于互斥视图切换：凹陷底容器，选中项凸起为内容表面；`tablist` / `tab` + `aria-selected`。

### 5.12 状态标签（Chip）

- 小号圆角矩形，图标 + 短文字。
- 色调映射固定：进行中 → 凹陷底 + 旋转图标；成功 → 强调柔和底；失败 → 危险柔和底，附错误详情提示。
- 连续的同类状态合并为一个，不堆叠。

## 6. 滚动容器

1. **统一的细滚动条样式**：细、无箭头、轨道透明，仅在指针悬停或内部获得焦点时淡入；所有局部滚动区都使用它，不出现浏览器默认样式。
2. **页面级滚动只属于浏览型外壳**；工作型外壳的页面本身不滚动，只在面板内部滚动。
3. **一个区域一个滚动容器、一个方向**；禁止同方向嵌套滚动；禁止横向滚动，溢出用截断或换行解决。
4. **面板三段式**：固定头部 + 弹性滚动主体 + 固定底部（输入区 / 操作栏）。头部与主体之间用分隔线而非阴影。
5. **按可见条目数限高**：列表型滚动区（侧栏分组、下拉选项、历史菜单）以"N 条完整可见"计算最大高度，使末条恰好完整显示，暗示下方还有内容。条目尺寸改变时同步更新该计算。
6. 限高的弹性列表中，条目禁止收缩，否则会被压扁而不是滚动。
7. **对话 / 日志类**滚动区在新内容或错误出现时自动滚到底部。
8. 自增长文本框设最小 / 最大高度，超出最大高度后内部滚动，使用同一滚动条样式。
9. 第三方嵌入内容（如 iframe 内的画布）如可注入样式，滚动条外观应与本规范一致。

## 7. 折叠与展开

### 7.1 分组折叠（Disclosure）

- 触发器是放在**标题元素内部**的整行按钮，声明 `aria-expanded` 和 `aria-controls`。
- 指示图标统一用**右向箭头**，展开时旋转 90°；不用加 / 减号，不在上下箭头之间切换图标。
- 分组的附加操作（如"新建"）放在标题行右侧，与触发器并列，不放进触发器内部。
- 被控区域用"隐藏"而非"卸载"实现，保留内部状态与滚动位置。
- 在折叠状态下执行"向该组添加内容"时，先自动展开再进入编辑。
- 默认展开；如需记忆折叠状态，存为本地偏好。
- 可能很长的分组必须配合按条目数限高。

### 7.2 下拉展开

- 指示图标用**下向箭头**，展开时旋转 180°。
- 展开期间触发器保持按下 / 聚焦外观。

### 7.3 面板显隐

- 侧面板开关使用 `aria-pressed`；开启时按钮切到"强调"色调。
- 面板关闭时**隐藏而不卸载**，保留内容与滚动位置。
- 面板头部提供关闭按钮，与外部开关等价。

## 8. 加载、骨架屏、空状态与错误

### 8.1 选择规则

| 场景 | 方案 |
| --- | --- |
| 结构已知的首次加载（卡片网格、列表、历史） | **骨架屏** |
| 结构未知或由第三方渲染（iframe、外部预览） | **居中加载指示**（旋转图标 + 文字） |
| 用户触发的操作（保存、测试、创建、发送） | **控件内旋转指示 + 禁用控件** |
| 等待异步回复（如 AI 首个响应） | 内容流末尾放"头像 + 旋转图标"占位 |
| 后台刷新（已有缓存） | 不显示加载态，直接替换 |
| 很快完成的请求 | 延迟一个短阈值再显示加载态，避免闪烁 |

### 8.2 骨架屏

- **形状与最终内容一致**：复用同一网格、同一卡片外壳、同样的内边距与宽高比，只把内容换成凹陷色占位块。替换为真实内容时**零布局位移**。
- **只画结构，不画细节**：预览区一块、标题一条、元信息一条短条；不画图标、按钮、悬停操作。
- **数量**：铺满首屏可见区域即可，不按真实数量渲染。
- **动效**：占位块柔和脉动；真实内容以淡入方式替换；遵守减弱动效偏好。
- **无障碍**：容器标记忙碌状态并提供仅读屏可见的"加载中"文字；占位块对读屏隐藏。
- **归属**：通用占位块属于通用组件层；特定布局骨架（如卡片骨架）与真实组件放在一起，结构变化时同步修改。
- **局部骨架**：侧栏、菜单等小区域使用与条目同高的占位行，条数不超过可见条目上限。
- 延迟显示阈值、骨架数量作为常量放在组件文件顶部。

### 8.3 第三方 / iframe 加载

- 就绪前用透明度隐藏（而不是移出布局），保证其能正常完成布局；就绪后淡入，期间显示自有加载指示，遮住第三方自带的加载画面。
- 缩略图懒加载；无缩略图时显示由对象 ID 确定性生成的占位图形，而非空白。

### 8.4 空状态

- 区分**真正为空**（引导创建）与**筛选无结果**（提示调整条件），两者文案不同。
- 页面级空状态居中、弱提示文字；小区域使用一行弱提示。不使用装饰插画抢占内容的注意力。

### 8.5 错误

- 页面级错误：内容区顶部的危险柔和底提示条，声明为 `alert`，不阻断其余内容。
- 局部错误：出现在错误发生的位置（内容流末尾、按钮旁），不弹全局对话框。
- 长错误截断显示，完整内容放在提示中，并写入日志。
- 轻量成功反馈（如"已复制"）在原位置短暂替换图标后自动恢复，不使用全局 Toast。

## 9. 动效

### 9.1 动效的逻辑

动效只回答一个问题：**这个东西从哪里来、到哪里去。** 因此：

- 只在**状态变化**时出现（出现、消失、展开、选中、切换），静止界面中没有动效。
- 动效方向与空间关系一致：下拉从触发器方向弹出；侧面板从其所在的边缘滑入；内容从下方轻微上浮淡入。
- 动效幅度小：位移以几像素计、缩放接近 1；用户应该"感觉到"而不是"看到"它。
- 除加载旋转与骨架脉动外，不做循环 / 装饰动画。

### 9.2 时长分档

| 档位 | 用于 |
| --- | --- |
| 短 | 颜色、边框、背景、透明度的过渡（悬停、焦点、选中） |
| 中 | 位移、旋转、缩放（箭头旋转、卡片上浮、开关滑块） |
| 长 | 大面积内容淡入（iframe 就绪、面板入场） |

- 全局只使用一条"快进慢出"的主缓动曲线，让元素迅速响应、平稳停下。
- 不在使用处写任意时长；需要新档位先加 Token。
- 过渡只列出真正变化的属性，不使用"所有属性"过渡。

### 9.3 入场动画角色

| 动画角色 | 形式 | 用于 |
| --- | --- | --- |
| 淡入 | 透明度 + 轻微上浮 | 卡片、消息、分区切换、骨架替换 |
| 弹出 | 透明度 + 轻微位移 + 轻微缩放 | 菜单、浮动面板、弹窗 |
| 面板滑入 | 透明度 + 水平位移 | 侧面板、抽屉 |
| 遮罩淡入 | **仅透明度** | 模态遮罩（遮罩位移会露出页面边缘） |

### 9.4 可访问性

- 全局遵守系统的"减弱动效"偏好，将所有过渡与动画缩短为近乎即时。
- 不用脚本定时动画绕过该偏好。
- 不以动效作为唯一的状态提示，状态必须同时有静态视觉表达。

## 10. 文字与图标

- **文字层级按角色命名**：页标题、弹窗标题、面板标题、正文、控件文字、元信息、辅助提示。新增层级先加入文字原语。
- **字重两档**：中等（控件、选中、字段标签）与半粗（标题）。
- **文字颜色三档**：主文字、次要文字、弱提示。
- 机器字符串使用等宽字体；标题字距由全局规则统一，使用处不写。
- **图标**：单一图标库、全局统一描边粗细；尺寸由所在控件档位决定；纯装饰图标对读屏隐藏。

---

## 11. 可访问性与国际化

- 所有可见文字（含无障碍名称、提示、占位符）都走国际化；仅示例性机器值可硬编码为常量。
- 布局容忍不同语言的长度差：按钮不定宽、名称截断、导航不换行。
- 回车提交必须排除输入法组合态，否则 CJK 输入确认候选词时会误提交。
- 交互元素使用原生按钮 / 链接 / 输入框，不在普通容器上绑定点击。
- 依赖悬停的功能在触屏设备上必须始终可达。
